# DFRP v0 CPU artifacts

`dev_panel/` is the first end-to-end root/contact-IK gate: a byte-identical
feasible control and one repaired flagged clip, each with full/brief rescreens,
exact sidecars, a DFRP manifest, a materialized training view, and an exact unit
table. The table contains two units and 76 legal 50-step starts.

`census/` is a deterministic reclassification of the existing 10,705-clip
screen and legacy root-only repair artifacts under the strict 10%, residual 5%,
and 8/15 cm DFRP policy. It does not claim that legacy files passed the new
root+IK qualification. `summary.md` is the human-readable result;
`manifest.json` is the 14 MB per-clip provenance artifact.

Both subdirectories are unsealed CPU results. Neither contains a policy outcome.
